# A better way in
- A new launch screen: FoxBox Voice opens straight away on the painted room and shows what it's doing (checking your invite, loading the voices, warming up the GPU), with the size and time left of any download, and a tip while you wait.
- A new app icon.
- The invite screen now sits on the painted studio scene: the card eases in, checks your code calmly, and opens FoxBox Voice as the room lights up.
- A wrong code gets a small shake and a red tint, so you know to look again. Reduce Motion gets fades and a still frame instead.
- In case you missed it: the IMPORT tab takes any audio file (WAV, AIFF, FLAC, MP3, M4A, or the sound of a video) through the same chain as a typed line or a take.
