## FoxBox Voice 1.0.0 beta 1: type a line, get a finished vocal

The voice studio from FoxBox, on its own. **It's a free, invite-only beta: you need an invite code to unlock it.**

- **Type or record:** pick a built-in voice, or record yourself with a count-in that stops at the bar count. Recordings are cleaned of room noise.
- **Shape it:** seven presets (PACT, LEGION, ABYSS, UNIT, GHOST, SIGNAL, RAW) and four macros: DEPTH, GRIT, MACHINE, SPACE.
- **Fit it to the bar:** 1, 2, 4, 8 or 16 bars, or AUTO. The last word lands on the beat, and `|` puts each part on a beat.
- **Export:** AIFF 24-bit or WAV, cut to the bar and tagged with BPM and key, BAKE-IN for your DAW or CLUB loudness for playing out, plus a rekordbox.xml with hot cue A on the first word. Drag it straight into Ableton or any DAW.

**Your invite code** looks like `FBV-XXXX-XXXX-XXXX`. FoxBox Voice checks it on your Mac and sends nothing anywhere. Each code is for one Mac. With no server, a code can't be stopped from being shared, so a code that gets shared around is withdrawn in the next update, and the Macs that used it ask for a new one. No code yet? [Get an invite](https://foxbox.tech/voice/#invite).

**Install:** download the DMG (macOS 14+, Apple silicon) and drag FoxBox Voice into Applications. It isn't notarized yet: on macOS 14, right-click → Open → Open; on macOS 15+, open it once, click Done, then System Settings → Privacy & Security → Open Anyway. Then unlock it with your code. Setup downloads the voices and the denoiser (about 300 MB); word timings for recordings are an optional ~2.9 GB install.

FoxBox Voice installs beside FoxBox, with its own settings, exports (`~/Music/FoxBox Voice`) and updates. Your voice, text and files never leave the Mac.
