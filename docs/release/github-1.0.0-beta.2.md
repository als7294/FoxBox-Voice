## FoxBox Voice 1.0.0 beta 2: a better way in

**Type a line. Get a finished vocal.** The voice studio from FoxBox, on its own, as a free beta unlocked with an invite code.

**What's new**
- **A new launch screen:** FoxBox Voice opens straight away on the painted room and shows what it's doing (checking your invite, loading the voices, warming up the GPU), with the size and time left of any download, and a tip while you wait.
- **A new app icon.** Still a fox.
- **The invite screen** now sits on the painted studio scene. The card eases in, checks your code calmly, gives a wrong code a small shake and a red tint, and opens the app as the room lights up. Reduce Motion gets fades and a still frame.
- **IMPORT, in case you missed it:** drop any audio file (WAV, AIFF, FLAC, MP3, M4A, or the sound of a video) on the IMPORT tab, and it goes through the same chain as a typed line or a recorded take.

**Already on beta 1?** FoxBox Voice updates itself at startup: it downloads only the parts that changed, checks each one's SHA-256, and restarts into beta 2.

**New here?** Download the DMG (macOS 14+, Apple silicon) and drag FoxBox Voice into Applications. It isn't notarized yet: on macOS 14, right-click → Open → Open; on macOS 15+, open it once, click Done, then System Settings → Privacy & Security → Open Anyway. FoxBox Voice asks for your invite code the first time you open it. It looks like `FBV-XXXX-XXXX-XXXX`, it's checked on your Mac, and nothing is sent anywhere. Then Setup downloads the voices and the denoiser (about 300 MB).

Your voice, text and files never leave the Mac.
