## FoxBox Voice 1.0.0 beta 4: a key works too

**Type a line. Get a finished vocal.** The voice studio from FoxBox, on its own, as a free beta unlocked with an invite code or a key.

**What's new**
- **Got a key instead of a code? Type it in.** The unlock field takes an invite code (`FBV-XXXX-XXXX-XXXX`) or a key. Case, spaces and symbols don't matter, and it's checked on your Mac like a code.

**Already on beta 3?** FoxBox Voice updates itself at startup: it downloads only the parts that changed, checks each one's SHA-256, and restarts into beta 4.

**New here?** Download the DMG (macOS 14+, Apple silicon) and drag FoxBox Voice into Applications. It isn't notarized yet: on macOS 14, right-click → Open → Open; on macOS 15+, open it once, click Done, then System Settings → Privacy & Security → Open Anyway. FoxBox Voice asks for your invite code or key the first time you open it. It's checked on your Mac, and nothing is sent anywhere. Then Setup downloads the voices and the denoiser (about 300 MB).

Your voice, text and files never leave the Mac.
